## 一、这份题单为什么这样排

### 1. 你的短板不是算法

CF 打过几百题的人，LeetCode Medium 的思路通常 3 分钟内就能出来。真正耗时的是：

| 在 C++ 里你写 | 在 Java 里你得写 |
|---|---|
| `sort(v.begin(), v.end(), cmp)` | `list.sort((a, b) -> ...)` |
| `pair<int,int>` / `vector<pair>` | `int[]` 或 `Map.Entry<>` |
| `mp[x]++` | `map.merge(x, 1, Integer::sum)` |
| `unordered_map<string,int>` | `Map<String,Integer> m = new HashMap<>()` |
| `long long` | `long`（且 `long` 也要字面量后缀 `L`） |
| `unsigned` | **没有**，只能用 `long` 顶 |
| `s.substr(l, r-l)` | `s.substring(l, r)` ← **右端是开区间** |
| `max(a,b)` | `Math.max(a,b)`（基本类型）/ `a.compareTo(b)`（对象） |
| `auto` | `var`（Java 10+，局部变量only） |

这些不是"知识点"，是**肌肉记忆**，只能靠写。所以题单里大量是 Easy/Medium，不是因为它难，而是因为它快——能一天写 5 遍。

### 2. 必须练 ACM 模式

国内后端笔试（牛客、赛码、笔试系统）用的是 ACM 模式：

```java
public class Main {
    public static void main(String[] args) throws IOException {
        // 自己读输入
        // 自己算
        // 自己打印
    }
}
```

LeetCode 的 `class Solution { public int[] twoSum(int[] nums, int target) }` 那种**核心代码模式，笔试里不存在**。你写完函数，没人帮你读输入。

**所以：D1–D10 用 LeetCode 核心代码模式（专注 Java API），D11 开始全部改成 ACM 模式自己写 main。** 这个切换点在阶段三开头，正好是项目 D10 红线之后，节奏对得上。

### 3. 难度配比

每天大约 **2 Easy + 3 Medium**，每周夹 1–2 道 Hard。

Hard 不要怕——你 CF 2000 分水平做 42.接雨水、76.最小覆盖子串、84.柱状图最大矩形、4.中位数，难度只相当于 CF 1600–1800。真正的难点是**写成 Java**。

## 二、五条执行规则

### 规则 1：严格计时，超时就停

| 难度 | 限时 |
|---|---|
| Easy | 10 分钟 |
| Medium | 25 分钟 |
| Hard | 40 分钟 |

**超时就停下看题解，但必须关掉题解自己从头重写一遍。** 然后标记这道题，在**第 3 天**和**第 7 天**各重做一次。

不重做 = 白刷。这是绝大多数人刷题没效果的唯一原因。

### 规则 2：禁写 C++

一题都不许用 C++ 写。哪怕 C++ 三分钟能过。你 C++ 已经够了，练的是 Java。

### 规则 3：写完必须口算复杂度

每道题写完，在注释里写一行：

```java
// 时间 O(n log n) 空间 O(1)
```

面试是要**口述**的。养成"写代码→报复杂度"的反射。

### 规则 4：每天挑 1 题改成 ACM 模式

D1–D10 期间，每天 5 题里挑最简单的那道，用 ACM 模式重写一遍（自己写 `main`、自己读输入）。本地造一个 `input.txt` 测。

不是为了练那道题，是为了让"自己处理输入输出"变成条件反射。模板见第四节。

### 规则 5：错题本只记两件事

建 `docs/leetcode-notes.md`，每题只记：

```
### 42. 接雨水（Hard，11-22）
卡在：单调栈的方向推错了，左高右低还是左低右高搞混
用到：Deque<Integer> st = new ArrayDeque<>(); st.peekLast()
```

**记"我卡在哪"和"用到的 Java API"**，不要抄题解代码。抄了等于没做。

## 四、ACM 模式模板

**背下来，每次笔试直接贴。**

### 4.1 最常用版（一行空格分隔的几个数）

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());

        // 读一整行数组
        st = new StringTokenizer(br.readLine());
        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = Integer.parseInt(st.nextToken());
        }

        // ... 算法 ...

        StringBuilder sb = new StringBuilder();
        sb.append(n).append(' ').append(m).append('\n');
        System.out.print(sb);
    }
}
```

### 4.2 多组测试数据版（"输入若干组直到 EOF"）

```java
public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        String line;
        StringBuilder sb = new StringBuilder();

        while ((line = br.readLine()) != null) {
            line = line.trim();
            if (line.isEmpty()) continue;

            StringTokenizer st = new StringTokenizer(line);
            int n = Integer.parseInt(st.nextToken());

            sb.append(n).append('\n');
        }
        System.out.print(sb);
    }
}
```

### 4.3 三个必须记住的坑

| 坑 | 说明 |
|---|---|
| **Scanner 太慢** | 10⁵ 以上的输入，`Scanner` 会比 `BufferedReader` 慢 5–10 倍，直接 TLE。**笔试一律用 `BufferedReader`** |
| **`System.out.println` 也慢** | 每行一次 IO 刷屏。用 `StringBuilder` 攒起来最后一次性 `print` |
| **不写 `package`** | 笔试提交的是 `Main.java`，**不能有 package 声明**，类名必须是 `Main` |

## 五、25 天之后怎么办

25 天做完 ≈ 125 题。但距离春招提前批（2027 年 2 月）还有**两个多月**，题单不是做完就完事：

### 第 26–55 天：二刷 + 补短板

1. **二刷标记过的题**：第一次超时看题解的题，全部再做一遍。目标是 25 分钟内独立通过。
2. **专项补强**：
   - 图论（最短路 Dijkstra/Floyd、最小生成树 Prim/Kruskal、并查集）—— 笔试偶考，但一考就是大题
   - 单调栈 / 单调队列 —— 84、239、42 这三个变体
   - 线段树 / 树状数组 —— CF 背景你熟，只需确认 Java 版能写
3. **ACM 模式专项**：把所有做过的题，挑 20 道用 ACM 模式从头写一遍。这是**笔试直接提分**的一项。

### 每天固定的 15 分钟

刷 **牛客网「笔试真题」** 的**选择题**（计算机网络 / 操作系统 / 数据库 / Java 基础）。这部分靠题量堆，和算法并行推进，不要到最后一个月才想起来。

### 关于"每天 5 题"这件事

**题单是队列，不是死命令。** 项目冲刺期（D1–D10、D18–D25）保底 3 题；项目轻松的日子补到 5 题。**不要跳过专题，宁可顺延。** 一天两题每个专题都摸到，好过一天五题然后断更一周。
