## 一、优先级：先看会被问什么

排名依据不是"内容多少"，而是**被问概率 × 你答不出的概率**。

| 优先级 | 模块 | 被问概率 | 你的风险 | 什么时候开始 |
|---|---|---|---|---|
| 🔴 最高 | **项目八股** | 100%（一定从简历问） | 现在还没素材 | 边做项目边攒 |
| 🔴 最高 | **Java 集合**（HashMap 原理） | ~100% | Java 新手，**风险最大** | 12/16 起 |
| 🟠 高 | **MySQL**（索引 / 事务 / MVCC） | ~90% | 没系统学过 | 12/23 起 |
| 🟠 高 | **计算机网络** | ~90% | 考研课水平 ≠ 面试问法 | 现在开始刷选择题 |
| 🟠 高 | **Java 并发** | ~80% | 完全空白 | 1/17 起 |
| 🟡 中 | **Redis** | ~70% | 项目会用到，但不懂原理 | 1/10 起 |
| 🟡 中 | **JVM** | ~60% | 空白 | 1/24 起 |
| 🟡 中 | **操作系统** | ~50% | 有基础 | 1/6 起 |
| 🟢 低 | **Spring / MyBatis 原理** | ~50% | 实习面试问得浅 | 1/28 起 |

### 为什么"项目八股"排第一

面试官永远从简历出发。**你简历上写的每一个技术点，他都有权利追问三层。**

```
简历写："使用 JWT 实现无状态鉴权"
第一层：JWT 由哪三部分组成？
第二层：为什么说它是"无状态"的？服务端真的什么都不存吗？
第三层：那用户退出登录怎么让 token 立即失效？
```

第三层答不出来，整段经历就打折。**这是唯一"你有而别人没有"的八股**，也是唯一能靠项目自然产出的八股。

所以：**每写完一个模块，趁热把卡片写了。** 事后回忆是回忆不出来的。

## 三、阶段一：11/21–12/15（项目期，只沉淀不背）

**这个阶段项目每天 8–10 小时 + LeetCode 2 小时，不要再加负担。** 只做两件极轻的事：

### ① 每天 15 分钟刷选择题

- 平台：牛客网「笔试真题」→ 选择题题库
- 顺序：**计算机网络 → 操作系统 → 数据库 → Java 基础**
- 用手机刷，通勤 / 睡前 / 排队，不要占用电脑时间
- 25 天目标：**500 题**

**为什么现在就做**：选择题是笔试的隐形分数（笔试通常是"选择题 + 2–4 道算法"），而且它靠题量堆，考前突击完全无效。现在开始每天 15 分钟，到 2 月你会有 1000+ 题的积累。

### ② 每完成一个项目模块，写 1–3 张卡片

写完代码当天的晚上，趁热写。对照 ROADMAP 的模块排期：

| 项目模块 | 该写的卡片 |
|---|---|
| D2 MyBatis-Plus CRUD | Mapper 为什么只有接口 / MP 的 BaseMapper 提供了什么 / 分页插件原理 |
| D3 工程规范 + 用户模块 | 统一返回体的设计 / 全局异常处理 @RestControllerAdvice / 参数校验 |
| D4 JWT + 权限 | JWT 三段结构 / 为什么无状态 / 拦截器 vs 过滤器 / 退出登录怎么失效 |
| 判题机（M2） | Docker 资源限制 / 为什么用冷启动 / 沙箱逃逸怎么防 |
| 消息队列 | 为什么判题要异步 / 削峰 / 消息丢失怎么处理 |
| Redis 缓存 | 缓存穿透 / 击穿 / 雪崩 / 一致性怎么保证 |

**25 天产出：约 40–60 张卡片**，这就是你的项目八股底稿。

## 四、阶段二：12/16–1/31（系统精读，6.5 周）

项目已经完成，进入八股主攻期。**每天 2 小时，切三块：**

| 时长 | 做什么 |
|---|---|
| 60 min | 精读**一个子主题**，产出 3–5 张卡片 |
| 30 min | 复习旧卡（间隔重复，见第七节） |
| 30 min | 牛客选择题 |

**注意"一个子主题"**：不是"今天学 MySQL"，而是"今天学 InnoDB 的 B+ 树索引为什么这么设计"。粒度太大 = 学不完 = 挫败。

## 五、阶段三：2/1–2/15（项目八股 + 模拟面试）

这个阶段**不再扩大知识面**，只做三件事：

### ① 简历逐行追问

把简历打印出来，每一行写三层追问，答不出来的补卡片。

```
简历："基于 Docker 实现了多语言代码安全沙箱"
  L1：怎么限制的？        → --memory --cpus --pids-limit --network=none
  L2：为什么用容器不用直接跑进程？ → 隔离性、可重现、资源可控
  L3：容器能百分百防住恶意代码吗？ → 不能，共享内核，还要靠 seccomp / 非 root / 只读挂载
```

**第三层是分水岭。** 能答第三层说明你真的做过，不是跟着教程抄的。

- 可以找我，我给你出题、追问、指出漏洞
- 也可以找同学对练
- **必须开口说，不能在心里想**。心里想是流畅的，一开口就卡

把所有标红的卡片再过一遍。目标是**看到标题能立刻讲出三层**。

## 七、卡片怎么写

### 7.1 格式：三句话 + 一个追问

```
### 标题（就是面试官会问的那句话）

**一句话**：用一句话回答，不带术语堆砌。

**三层展开**
1. 第一层
2. 第二层
3. 第三层

**追问**
Q: ...
A: ...
```

### 7.2 完整示例

```
### 为什么 MyBatis 的 Mapper 只有接口就能用？

**一句话**：MyBatis 在启动时用 JDK 动态代理，给你生成了一个实现类。

**三层展开**
1. 你写的 UserMapper 只是个接口，编译后是 .class，没有方法体。
2. @MapperScan 扫描到它，注册进 Spring 容器的不是接口本身，
   而是 MapperProxy —— 一个实现了 InvocationHandler 的代理。
3. 你调用 userMapper.selectById(1)，实际进的是 MapperProxy.invoke()；
   它按"接口全限定名 + 方法名"拼出 SQL 语句 ID，
   交给 SqlSession 执行。

**追问**
Q: 能被 @Autowired 注入吗？
A: 能。容器里放的是代理对象，代理类实现了 UserMapper，类型对得上。
Q: 不写 @MapperScan 行不行？
A: 不行。Spring 默认扫的是 @Component 系注解，
   接口上的 @Mapper 需要 MyBatis 自己的扫描器。
```

### 7.3 让卡片真正被记住的四件事

| 做法 | 说明 |
|---|---|
| **间隔重复** | 第 1、3、7、15 天各复习一次。用 Anki，或在卡片上标复习日期 |
| **讲出来** | 每天挑一张卡，对着手机录音讲 1 分钟。**讲不顺就是没懂**，比看十遍管用 |
| **从项目找锚点** | 每张卡加一句"我项目里哪里用到 / 为什么没用上"。没有锚点的卡片记不住 |
| **对比式记忆** | TCP vs UDP、B+ 树 vs B 树、悲观锁 vs 乐观锁、进程 vs 线程、RDB vs AOF —— **对比表比段落好背十倍** |

### 7.4 绝对不要做的事

❌ **抄博客。** 抄下来的那一刻你就忘了，而且抄完会产生"我学过了"的错觉。
✅ 用自己的话写，写不出来的部分就是你没懂的部分——那才是你该去查的地方。

## 八、选择题怎么刷

| 项 | 说明 |
|---|---|
| 平台 | 牛客网 → 题库 → 笔试真题 → 选择题 |
| 顺序 | 计算机网络 → 操作系统 → 数据库 → Java 基础 → 数据结构 |

## 九、六个反面清单

1. ❌ **项目期硬背八股** → 项目拖垮、八股也没记住。项目期每天 35 分钟上限。
2. ❌ **收藏代替学习** → 建 Notion 贴 20 篇文章标"待复习"，三个月后还在那儿。**收藏 ≠ 学习**。
3. ❌ **抄博客做笔记** → 产生"我学过了"的错觉。必须用自己的话写。
4. ❌ **只背"是什么"，不背"为什么"** → 面试官问"为什么不这么做"就崩。每张卡必须有追问。
5. ❌ **心里默念代替开口** → 心里想是流畅的，一开口就卡。**必须出声**。
6. ❌ **最后一个月才开始** → 八股靠的是理解 + 间隔重复，这是时间的函数，突击无效。
