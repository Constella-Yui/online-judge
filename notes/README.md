# 每日笔记

> 一天一个文件，命名 `YYYY-MM-DD.md`。
> 不追求完整，只求**一年后翻回来还能看懂**。

---

## 怎么用

1. 每天结束时新建 `YYYY-MM-DD.md`
2. 从下面的「每日模板」复制骨架
3. 今天想明白的、踩过的坑、跑通的代码，写进去
4. 在文末的「索引」里加一行

**如果某天没时间写**，就只写一行「今天做了什么」。空文件也好过没文件。

---

## 四条规则

| 规则 | 说明 |
|---|---|
| **只记原来不知道的** | 教科书上印着的不抄，抄了也不会看 |
| **代码先跑通再贴** | 笔记里的代码必须是能运行的，否则三个月后你会怀疑人生 |
| **记"为什么"，不记"是什么"** | "ArrayList 是数组"谁都知道，"扩容要拷贝 1.5 倍"才有价值 |
| **标注没搞懂的** | 每天至少留一条「还没搞懂的」，第二天从这里开始 |

## 和别的文档的分工

| 文档 | 管什么 |
|---|---|
| `notes/`（这里） | **按时间**记录我每天学了什么、踩了什么坑 |
| `docs/env-principles.md` | **按主题**讲透了环境原理（PH 的 P，长期有效） |
| `docs/git-cheatsheet.md` | git 命令速查 |
| `docs/leetcode-plan.md` | 25 天题单 |
| `docs/bagu-plan.md` | 八股排期与卡片方法 |
| `docs/bagu-cards.md` | 八股卡片正文（还没建，D2 之后开始攒） |
